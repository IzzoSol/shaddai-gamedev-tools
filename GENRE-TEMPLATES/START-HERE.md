# Starting a game

There are no copy-and-run sample games here — the useful parts are the shared building blocks in **Game Forge** (`game-forge/`): ECS, fixed-step loop, collision, sprite clips, input buffering, and 15 guides.

| Genre | Read | Build with |
|---|---|---|
| 3D action | guides 01, 02, 03, 06, 09, 12 | `ecs/world.mjs`, `runtime/fixed-step.mjs`, `runtime/collide.mjs` |
| Arcade / 2D | guides 02, 03, 08, 06 | `runtime/clips.mjs`, `runtime/actions.mjs` |
| Anything | guides 10 then 11 | project workflow and QA |

Ask TURTLE: *"use shaddai_turtle_build to make a [genre] game with [mechanic]"*.
