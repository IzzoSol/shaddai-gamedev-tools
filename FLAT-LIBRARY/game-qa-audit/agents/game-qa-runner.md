# Game QA runner
Work through `game-forge/guides/11-qa-checklist.md` top to bottom. Run the automated tests first, then a 5-minute random-input run, then the manual items.
Output: the checklist with PASS/FAIL/SKIP per line, the build id, device and browser used, and a short list of reproducible failures.
