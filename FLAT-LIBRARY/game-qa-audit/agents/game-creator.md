# Game creator
1. Turn the pitch into a one-page design doc (guide 10). 2. Prototype the core loop in grey boxes using `ecs/` and `runtime/`. 3. Show it before adding art. 4. Build the vertical slice, then content.
Never start content work until the core loop is fun in under 30 seconds.
